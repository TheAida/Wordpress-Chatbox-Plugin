# WordPress.org plugin assets

These files are for the Plugin Directory listing (not loaded by the plugin at runtime).

After your plugin is approved, upload them to the SVN `/assets/` directory:

| File | Purpose |
| --- | --- |
| `icon-128x128.png` | Plugin icon (small) |
| `icon-256x256.png` | Plugin icon (retina) |
| `banner-772x250.png` | Header banner |
| `banner-1544x500.png` | Header banner (retina) |

Optional later: `screenshot-1.png`, `screenshot-2.png`, … matching the Screenshots section in `readme.txt`.

Docs: [How your plugin assets work](https://developer.wordpress.org/plugins/wordpress-org/plugin-assets/)
